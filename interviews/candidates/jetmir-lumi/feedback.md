The largest concern was the gap between his practical architecture experience and his performance on core Java fundamentals. Topics such as JVM internals, memory organization, Java Streams, functional interfaces, ACID principles, database fundamentals, Git concepts, and JPA optimization showed weaker depth than expected for a Senior Java Developer role. Several answers lacked precision, and concepts such as N+1 queries, memory management, and rebase workflows were either partially answered or not well understood. Before client-facing technical interviews, strengthening these Java and database fundamentals would significantly improve his overall profile.
